# spec-driven templates

本目录保存 `spec-driven` schema 的 artifact 模板。

## 子目录

- （无）

## 文档

- [proposal.md](./proposal.md) — 变更提案模板，聚焦 Why / What Changes / Capabilities / Impact。
- [spec.md](./spec.md) — 规格增量模板，提供 ADDED Requirements 与 Scenario 的基础骨架。
- [design.md](./design.md) — 技术设计模板，覆盖 Context、Goals/Non-Goals、Decisions 与 Risks/Trade-offs。
- [tasks.md](./tasks.md) — 实施任务清单模板，使用分组编号与复选框任务项。
