## 安全检查范围

- setup 是否只修改项目内工作流文件。
- 是否避免覆盖用户已修改的 `.workflow/templates/`。
- 是否避免执行破坏性命令。

## 检查结果

| 项目 | 结果 | 证据 |
| --- | --- | --- |
| 不覆盖已有项目模板 | pass | setup 规则要求只补缺失模板，除非用户明确要求重置 |
| 不执行破坏性删除 | pass | setup 仅初始化或更新结构 |
| 不根据文件名猜测 docs 描述 | pass | docs 索引规则要求先阅读文档内容 |

## 风险与处理

- 风险：老项目已有入口文件内容复杂，注入治理区块时可能误改其他内容。
- 处理：只更新 `WORKFLOW:GOVERNANCE` 受管理区块；没有区块时追加，不整文件重写。

## 结论

当前 setup 规则没有引入已知破坏性操作。
