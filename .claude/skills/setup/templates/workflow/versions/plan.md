## 版本目标

建立 setup 技能初版，让新项目或老项目可以初始化工作流基础结构。

## 范围

### 包含

- 创建 `.workflow/` 与 `docs/` 基础结构。
- 创建两个治理文件。
- 注入 `AGENTS.md` 与 `CLAUDE.md` 的治理加载规则。
- 复制 skill 内置模板到 `.workflow/templates/`。
- 检查并重建老项目的 docs 索引。

### 不包含

- 设计 Clarify 或 Delivery 技能。
- 推进具体业务需求。
- 编写项目业务文档。

## 里程碑

1. 完成 setup 技能结构。
2. 完成内置模板。
3. 在样例项目中验证 setup 输出。

## 完成定义

- setup 执行后，目标项目包含必要目录、治理文件、模板副本和入口加载规则。
- 老项目已有 docs 时，索引能覆盖本层子目录和本层文档。

## 风险与阻塞

- 老项目文档较多时，索引重建需要逐个阅读文档，不能用文件名猜测。
