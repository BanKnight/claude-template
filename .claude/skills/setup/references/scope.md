# setup 执行边界

`setup` 只负责建立和更新工作流基础设施。

## 负责

- 初始化或更新 `.workflow/`。
- 初始化或更新 `docs/`。
- 创建或维护两个治理文件。
- 把治理文件加载规则注入 `AGENTS.md` 和 `CLAUDE.md`。
- 将 skill 内置模板复制为 `.workflow/templates/` 的项目本地模板副本。
- 在老项目中根据现有 `docs/` 内容重建索引。

## 不负责

- 需求澄清。
- 产品或技术设计。
- 版本规划。
- 任务执行。
- 代码评审、测试或安全审查。
- 长期业务知识沉淀。

这些动作应由后续 workflow skills 负责。
